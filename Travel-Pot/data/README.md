## 데이터셋 버전 이력 (`archive/model/`)

단계가 바뀌면 주 버전, 같은 단계의 보완은 소수점 버전입니다. 앞 번호는 만든 순서입니다.

| 순서 | 파일 | 열 수 | 무엇이 달라졌나 |
| --- | --- | --- | --- |
| 01 | v1 | 28 | 기본선. 인구·어린이집·소아과 기본 변수와 위험 라벨 |
| 02 | v1.1 | 31 | 어린이집 1년 증감 3개 추가 (이후 버전에서 제외) |
| 03 | 실험 (면적·밀도) | 32 | v1.1에서 갈라져 면적·인구밀도 변수를 시험한 갈래. 이후 04~07 버전에는 이어지지 않았고, v3.2에서 경계 기반 면적으로 다시 반영 |
| 04 | v2 (1단계) | 45 | 설립유형(국공립·민간·가정…), 휴지, 폐원·신규 변수 |
| 05 | v2.1 | 62 | 시도 소아과 개·폐업, 병원급 의료기관(LOCALDATA) 변수 |
| 06 | v2.2 | 66 | 폐원·휴지 정의 보완 (연말 휴지시설, 운영중단 추정 등) |
| 07 | v3 (2단계) | 86 | 외부 변수 20개: 총인구, 고령·여성 비율, 지방소멸위험지수, HIRA 시설·전문의, 재정자립도 |
| 08 | v3.1 | 89 | 코드 매핑 보정(증평군·미추홀구, 행안부 코드표), 0~14세 인구·0~5세 비율·노령화지수 |

## 보관 (`archive/`)

- `panel/`: 통합 패널 초기본(정원 없음, 어린이집 2021년부터), 패널의 원재료인 시군구별 어린이집·소아과 자료(2009~2026)
- `model/`: 위 버전 이력의 이전 파일
- `results/`: 사분면 결과 v4(SHAP 시트 없음), v3.1 데이터로 처음 돌린 RF 예측 결과

## 레포에 넣지 않은 것

- 서울형 소아의료체계 기관 목록(기관명·전화번호 포함)과 시설 단위 원자료는 공개 레포에 올리지 않았습니다.
