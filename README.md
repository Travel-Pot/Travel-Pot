
# Travel-Pot

> 공공데이터로 **3년 뒤 보육·소아의료 공백 위험 지역**을 예측하고, 지역별 위험 이유까지 보여주는 시군구 단위 분석 프로젝트

공공데이터활용 AI 경진대회 출전팀 **여행팟(Travel-Pot)** 의 프로젝트 저장소입니다.

## 📌 프로젝트 소개

- **대회**: 공공데이터활용 AI 경진대회
- **주제**: 보육·소아의료 공백 위험 지역 예측
- **진행 기간**: 2026.10.01 ~ 10.16
- **분석 단위**: 전국 229개 시군구 × 2016~2025년

### 배경

저출생으로 아이가 줄면 어린이집이 먼저 문을 닫고, 소아과도 지역에서부터 사라집니다. 2016년을 100으로 놓으면 2025년 0~5세 인구는 약 57, 어린이집은 약 63까지 줄었고, 소아과가 한 곳도 없는 시군구는 53곳에서 58곳으로 늘었습니다. 소아과는 전국 합계로는 유지되는 것처럼 보여도 지역 공백이 커지고 있습니다.

기존 공개 서비스는 시설 현황을 보여주는 데 그칩니다. 지자체가 지원 대상을 정하려면 **공백이 생기기 전에** 위험 지역을 찾아낼 수 있어야 합니다.

### 목표

- 어린이집과 소아과를 하나의 위험 판단으로 묶어 **3년 뒤 급감 위험**을 예측한다.
- 지역별로 **왜 위험한지**(SHAP)를 함께 제시해 지원 방식을 정할 근거를 준다.
- 이미 공백인 지역과 곧 공백이 될 지역을 구분해 정책 대상을 나눈다.

## 🗃 데이터

공공데이터를 시군구 코드 기준으로 통합해 **229곳 × 17년(2010~2026), 3,893행의 패널 데이터**를 만들었습니다. 모델 학습에는 2016~2022년 기준연도 7개를 써서 1,603행을 사용했습니다.

| 구분 | 데이터 | 출처 |
| --- | --- | --- |
| 보육 | 어린이집 수·정원·현원, 설립유형, 폐원·휴지 | 어린이집정보공개포털, KOSIS |
| 의료 | 소아청소년과 의원 수, 개·폐업 | 건강보험심사평가원(HIRA) |
| 인구 | 0~5세·0세 인구, 출생아 수, 총인구, 65세 이상 비율, 20~39세 여성 비율 | KOSIS |
| 지역 | 지방소멸위험지수, 재정자립도, 면적(경계 파일 기반 추정) | KOSIS, 공공데이터포털 |
| 경계 | 행정동 경계(2025-12-31) | 공개 경계 파일 |

### 전처리

- 출처마다 다른 지역 코드를 행정안전부 5자리 코드로 통일하고, 통합·분리·편입·명칭 변경(청주시+청원군, 군위군 대구 편입, 미추홀구 등)을 **이름이 아닌 코드 매핑표**로 처리했습니다.
- 수원시 영통구 같은 일반구는 시 단위로 병합했습니다.
- 시군구 값을 모두 더해 KOSIS 전국 합계와 대조하는 교차 검증을 했고, 모든 연도·변수에서 일치했습니다.
- 원자료의 오류(소아과 개·폐업 수 과다, 일부 시도 정원 입력 오류)는 원자료를 다시 조회해 바로잡았습니다.

### 위험 라벨

t년 자료로 **t+3년**을 예측합니다.

| 라벨 | 정의 |
| --- | --- |
| 어린이집 위험 | 3년간 어린이집 수 감소율이 그 해 전국 시군구 중 하위 20% (해마다 비율 고정) |
| 소아과 위험 | 3년 뒤 소아과 의원 수가 줄었고, 0~5세 1천명당 의원 수가 전국 중앙값 미만 |
| **최종 라벨(공백 위험)** | 위 둘 중 하나라도 해당 (양성 비율 23~28%) |

"소아과 0곳"은 새로 0곳이 되는 지역이 연 2~3곳뿐이라 라벨에서 제외하고, 현재 공백을 보여주는 축으로 따로 썼습니다.

## 🔬 분석 및 모델링

1. **변수 54개** (모두 t년 이하 정보): 인구·출생, 어린이집 규모·유형·폐원·휴지, 소아과, 시도 소아과 동향, 인구구조·재정. 단순 시설 수 대신 **영유아 1천명당 시설 수** 같은 수요 대비 공급 지표를 썼습니다.
2. **모델 비교**: 로지스틱 회귀(기본선), 랜덤포레스트, GBM. 표본이 작아(1,603행) 딥러닝 대신 트리 모델과 설명에 집중했습니다.
3. **시간 순 검증**: 과거로 학습하고 미래로 평가했습니다 (2016~2018 → 2021, 2016~2019 → 2022). 평가 시점에 알 수 없는 라벨은 학습에서 뺐습니다.
4. **최종 모델**: 랜덤포레스트(500그루, `min_samples_leaf=5`), 2016~2022 전체로 학습. 2027년 예측은 2024년 자료, 2028년 예측은 2025년 자료를 사용합니다.
5. **해석**: SHAP으로 전체 변수 중요도와 지역별 위험 이유 3가지를 산출했습니다.

### 모델 성능

| 지표 | 결과 |
| --- | --- |
| AUC | 0.790 |
| PR-AUC | 0.574 |
| Precision@20 (상위 20곳 적중률) | 0.725 |

위험 지역이 전체의 약 25%인 불균형 문제라 정확도 대신 AUC, PR-AUC, 상위 k곳 적중률로 평가했습니다.

### 검증 과정에서 바로잡은 문제

처음 결과에서는 **소아과가 0곳인 정선·진도·고흥이 "가장 안전"** 으로 나왔습니다. 라벨이 "공백 여부"가 아니라 "3년간 얼마나 줄었는가"를 재기 때문에, 이미 더 줄어들 게 없는 지역이 안전으로 학습된 것입니다. 그래서 점수만 쓰지 않고 **급감 위험 × 현재 공백** 두 축으로 지역을 나눴습니다.

## 📊 결과

| 유형 | 의미 | 2027 | 2028 |
| --- | --- | --- | --- |
| ① 최우선 지원 | 이미 공백 + 급감 위험 | 4곳 | 3곳 |
| ② 예방 대상 | 아직 유지 + 급감 위험 | 42곳 | 43곳 |
| ③ 구조적 공백 | 이미 공백 + 급감 위험 낮음 | 54곳 | 55곳 |
| ④ 관찰 | 해당 없음 | 129곳 | 128곳 |

- **2028년 위험점수 상위**: 전남 목포시, 경남 거제시, 부산 사상구, 경기 동두천시
- **지역 분포**: ②는 경남 남해안·부산 서부에, ③은 강원 동부·경북 북부·전남 남해안 군 지역에 몰려 있습니다.
- **위험 이유 요약**: 상위 지역에서는 "아이는 급격히 줄었는데 시설은 아직 많은" 패턴이 자주 나타났습니다.
- **강건성**: 시도 변수를 빼고 다시 계산해도 순위 상관이 0.95~0.97로 유지됩니다.
- **인터랙티브 위험 지도**: 229개 시군구를 유형·위험점수로 색칠하고, 지역별 위험 이유와 2027/2028 전환을 제공합니다.

### 정책 활용

- ① **최우선 지원**: 보육·소아의료 묶음 지원
- ② **예방 대상**: 폐원 전 통합·전환, 정원 조정, 소아과 개원 유지 지원
- ③ **구조적 공백**: 거점 어린이집, 순회·원격 소아진료, 인근 시군 공동 이용
- ④ **관찰**: 매년 점수를 갱신하고 유형이 바뀐 지역 점검

## ⚠️ 한계 및 책임 있는 활용

- 위험점수는 확률이 아니라 **지원 우선순위를 정하기 위한 순위용 점수**입니다. 개별 시설의 존폐나 지역의 우열을 단정하는 근거로 쓰지 않으며, 결과는 시군구 단위로만 공개합니다.
- 학습 가능한 기준연도가 7개뿐이고, 면적은 경계 파일 기반 추정값입니다.
- 2010~2015년 시군구 단위 어린이집 자료가 없습니다.
- 응급의료기관 수는 시군구 시계열을 구하지 못했고, 아동병원은 공식 분류가 없어 반영하지 못했습니다.
- 읍·면 단위 접근성은 반영하지 못했습니다.
